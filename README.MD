## 使用ツール
https://dash.cloudflare.com/
- githubに上げたHTMLを公開してくれるサービス(無料)

https://supabase.com/
- githubに上げたリポジトリのDBとして使えるサービス(無料)

https://dashboard.render.com/
- 常駐node.jsサーバとして使用。ずっと起動し続けてもらいます(無料プラン)
